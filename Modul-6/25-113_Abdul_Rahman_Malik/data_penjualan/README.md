# Cara Menjalankan
1. Jalankan XAMPP (Apache + MySQL).
2. Buka phpMyAdmin, tab Import, pilih `database.sql` (otomatis membuat database `data_penjualan`).
3. Salin folder ini ke `htdocs/data_penjualan`.
4. Sesuaikan user/password MySQL di `koneksi.php` bila perlu (default: root, tanpa password).
5. Buka http://localhost/data_penjualan/
